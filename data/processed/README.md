# Processed GPFG teaching data

These files are generated by `scripts/prepare_gpfg.R` from the archived official
NBIM year-end equity holdings.

For the course, start with `gpfg_equities_latest.csv`, then move to
`gpfg_equities_last_10_years.rds` after students understand one-year data. The
`gpfg_equities_full_history.rds` file is an advanced resource because the long
series contains historical coverage, classification, and company-identity
breaks.

The stable filenames do not change each year. Run
`Rscript scripts/update_gpfg.R` after NBIM publishes a new year-end report; the
script downloads missing annual files, rebuilds these datasets, and validates
the result.

See `reports/gpfg-data-audit.md` and `gpfg_data_dictionary.csv` before using the
data in a new chapter or assignment.
