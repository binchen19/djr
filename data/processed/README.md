# Advanced processed data

The GPFG files are generated by `scripts/prepare_gpfg.R` from the archived
official NBIM year-end equity holdings.

The learner-facing CSV files are stored directly in `data/`, so the textbook
can use short paths such as `data/gpfg.csv`. This `processed`
folder is only for advanced R files, source manifests, validation checks, and
maintenance summaries.

The `gpfg_equities_full_history.rds` file is an advanced resource because the
long series contains historical coverage, classification, and company-identity
breaks.

The stable filenames do not change each year. Run
`Rscript scripts/update_gpfg.R` after NBIM publishes a new year-end report; the
script downloads missing annual files, rebuilds these datasets, and validates
the result.

See `reports/gpfg-data-audit.md` and `data/gpfg_data_dictionary.csv` before
using the data in a new chapter or assignment.

Two other learner-facing files keep specialized preparation code outside the
beginner chapters:

- `data/debate_turns.csv` is generated from `data/debate.txt` by
  `scripts/prepare_debate.R`.
- `data/world_boundaries.csv` is generated from Natural Earth data by
  `scripts/prepare_map_boundaries.R`.

The corresponding chapters import these CSVs with `read_csv()` and continue
with the same tidyverse workflow used throughout the book.
